### Projeto com base em um desafio Front End, uma aplicação WEB em **React + Next** que ultiliza a API da wikipedia para renderizar informações de animais em tela, tambem consta telas de login e cadastro que estão ultilizando um Mock. Todo  o ambiente é configurado com **Docker**, facilitando o deploy e o ambiente de desenvolvimento.

## 🚀 Tecnologias Utilizadas

- [Next.js](https://nextjs.org/) — Framework React moderno para aplicações web
- [Tailwind CSS](https://tailwindcss.com/) — Utilizado para estilização rápida e responsiva
- [Wikipedia API](https://www.mediawiki.org/wiki/API:Main_page) — Usada para buscar dados informativos
- [Docker](https://www.docker.com/) — Contêineriza toda a aplicação para facilitar o deploy
- [TypeScript](https://www.typescriptlang.org/) — Tipagem estática para JavaScript
